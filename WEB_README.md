# GymLog web versions

The current app is at **https://nickkkk3105.pythonanywhere.com/**.

The former GitHub Pages URL redirects there. The website now runs from `cloud/` with a Python/Flask server, private SQLite storage and one owner password. Saved templates and finished sessions can be loaded on another device. Unsaved drafts are not synchronised.

See [cloud/README.md](cloud/README.md) for the implementation, editable exercise catalogue, PythonAnywhere setup, tests and backup instructions.

The root `web.js`, `web.css`, `web-model.mjs` and `web.test.mjs` are retained source from the original session-only browser prototype. They are not the active journal app. The Python/CustomTkinter desktop starter is also independent.
