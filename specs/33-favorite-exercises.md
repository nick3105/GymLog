# 33 — Favourite exercises in the workout builder
Assignee: Gaia Bandini

## Why
People often use the same exercises each week. Marking those exercises as favourites lets them
find them quickly while creating or editing a workout (PLN-02).

## What
This task is claimed on 17 November 2026. Each signed-in user will be able to mark a catalogue
exercise as a favourite with a star and see their own favourites first in the Create/Edit workout
exercise selector. The detailed interaction and placement will be agreed before implementation.

## Out of scope
Changing the shared exercise catalogue, sharing favourites with other users, automatically
favouriting an exercise based on training history, new libraries, or changes to completed
workouts.

## Done when
The final spec will state the storage rule, the exact phone interaction, user isolation tests,
and a 375 px verification before any code is written.
